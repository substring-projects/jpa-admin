Spring Boot JPA Admin Starter

This dependency-only module brings core, UI and auto-configuration into a servlet Spring Boot application. It has no Java API of its own; its sources classifier contains its POM and module documentation.

Configure spring.jpa.admin.security.password for the default configured account. For dedicated users and groups, add the matching jpa-admin-identity version and configure database mode and migrations. Identity is optional and not transitively included by this starter.
